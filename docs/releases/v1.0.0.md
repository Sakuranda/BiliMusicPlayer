# BiliMusicPlayer v1.0.0

首个公开版本，迁移当前网页播放器、B 站收藏夹导入及 Navidrome 客户端功能。

- 收藏夹解析、自动更新、歌手分类、歌词界面编辑歌曲信息、重新下载封面。
- 多 P 完整长列表：全局 / 每个视频只下载首 P、下载全部、取消全选，以及逐 P 选择；旧记录同样重新选择。
- 管理员用户名 / 密码设置，可选验证器 TOTP 2FA，默认关闭。
- 一条命令自动安装 Docker（如缺失）、下载 Release、构建并启动服务；两个自选域名自动 HTTPS，支持已有反向代理。
- 安装生成随机初始密码；升级保留曲库和账户，检查下载任务并备份数据库；提供完整备份与账户恢复命令。
- 全新公开仓库历史；发布包不含私人服务器配置、运行数据库、Cookie 或音频。

安装命令及准备工作见 [README](https://github.com/Sakuranda/BiliMusicPlayer#服务器部署)，账户和 2FA 见 [账户安全](https://github.com/Sakuranda/BiliMusicPlayer/blob/main/docs/账户安全.md)。

Docker 从发行版源码构建，首次安装需能访问 GitHub、Docker Hub、npm 和 PyPI。B 站下载仍取决于自己的 Cookie 和服务器 IP，若出现 412 请按运维教程处理。
